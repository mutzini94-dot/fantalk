# 열혈톡 (FanTalk)

투네이션 크리에이터–도네이터 다이렉트 소통 앱. 엑셀방송 크루가 열혈시청자와 폰으로 직접 이어지는 팬 관계 관리(CRM) + 메신저입니다.

## 구성

| 파일 | 설명 |
|------|------|
| [`index.html`](index.html) | 앱 인터랙티브 프로토타입 (iOS·Android 하이브리드, Capacitor 래핑 기준) |
| [`crew-talk-app.html`](crew-talk-app.html) | 위와 동일한 앱 소스 |
| [`crew-talk-plan.html`](crew-talk-plan.html) | 서비스 기획서 (PRD) |

## 핵심 기능 (Phase 1–2)

- **온보딩 · 로그인** — 인트로 3단계 + 투네이션/카카오/이메일 로그인
- **실시간 채팅** — 크루 채널 · 1:1 · 등급 전용방(VVIP/SVIP)
- **후원톡** — 투네이션 후원 연동 강조 카드, 후원톡 트레이, 후원 목표
- **팬 등급 관리(CRM)** — 열혈네이션 계승 일반/VIP/VVIP/SVIP 자동 산정, 프로필·메모·태그·세그먼트
- **접속 · 이벤트 알림** — 도네이터 접속, 후원, 등급 상승, 복귀 유도
- **인사이트 대시보드** — 후원 추이, 등급 분포, 리텐션, 관계 온도, 이탈 위험, 자동화 성과
- **자동화** — 카카오 알림톡 자동 발송(등급 달성·생일·기념일)

## 실행

정적 HTML이라 `index.html`을 브라우저로 열면 됩니다. 상단에서 **크리에이터 ↔ 도네이터** 역할을 전환하고, **LIVE**를 켜면 후원·채팅·등급·알림 파이프라인이 실시간으로 시뮬레이션됩니다.

## 상태

v0.3 프로토타입 (온보딩·로그인 · Phase 1–2 · 열혈네이션 등급 연동). 실 서비스는 WebSocket + FCM/APNs + 투네이션 후원 Webhook 아키텍처로 구현 예정.
